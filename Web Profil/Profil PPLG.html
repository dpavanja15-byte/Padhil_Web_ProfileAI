Pengertian PPLG

PPLG adalah singkatan dari Pengembangan Perangkat Lunak dan Gim, yaitu program keahlian di SMK yang mempelajari cara merancang, membuat, menguji, dan merilis perangkat lunak.

Cakupannya meliputi aplikasi web, aplikasi mobile, dan gim digital. Siswa belajar lewat praktik dan proyek, sehingga lulusannya siap masuk dunia kerja atau industri kreatif digital.

Kompetensi yang dipelajari

Pemrograman web

HTML, CSS, JavaScript, dan framework untuk membuat website.

Pemrograman mobile

Membuat aplikasi Android dan aplikasi lintas platform.

Pengembangan gim

Desain gim, grafis 2D, dan logika permainan.

Basis data

Merancang dan mengelola database untuk aplikasi.

Prospek kerja

Setelah lulus, siswa PPLG dapat berkarier sebagai:

  • Web developer
  • Mobile developer
  • Game developer
  • Software tester
  • UI/UX designer
  • Wirausaha digital

Siswa PPLG Membuat Gim Sederhana di Pekan Proyek

Ditulis oleh Tim Jurusan PPLG pada 15 September 2026

Siswa kelas XI PPLG mengikuti Pekan Proyek dengan tema pembuatan gim sederhana. Dalam kelompok kecil, mereka merancang alur cerita, membuat karakter dan tampilan, lalu memprogram permainannya sampai bisa dimainkan.

Di akhir kegiatan, setiap kelompok mempresentasikan gimnya dan mendapat masukan dari guru serta teman sekelas. Kegiatan ini melatih kerja sama tim, kreativitas, dan kemampuan memecahkan masalah.
